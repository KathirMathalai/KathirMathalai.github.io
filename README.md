# Freakazao — Physics Portfolio

Personal academic portfolio for research and computational work in theoretical and computational physics.

**Live site:** https://freakazao.github.io  
**Repository:** https://github.com/Freakazao/Freakazao.github.io

## Built with
- Semantic HTML
- Responsive CSS
- GitHub Pages

## Local preview
Open `index.html` in a browser. No build step or dependencies are required.

## Updating the site
- Edit research descriptions in `index.html` as projects progress.
- Add polished, reproducible computational projects when they are ready to share.
- Add a CV at `assets/cv.pdf` and a link to it once the final version is ready.
- Add professional contact links only after confirming the URLs.

## Publishing
The repository is named `Freakazao.github.io`. In GitHub, open **Settings → Pages** and ensure the site is deployed from the `main` branch, root folder. The site should then be available at https://freakazao.github.io.

Research descriptions are deliberately high-level. Do not publish unpublished data, code, or detailed methods without checking with the relevant supervisors and collaborators.
